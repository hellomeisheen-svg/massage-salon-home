# Структура проекта «Седьмое небо»

## Обзор папок
- `src/routes/` — **Маршрутизация (TanStack Router).** 
  - Каждый `.tsx` файл здесь соответствует странице или техническому маршруту.
  - `__root.tsx` — Корневой лейаут (Header, Footer, провайдеры).
  - `index.tsx` — Главная страница.
  - `$.tsx` — Универсальный обработчик 404.
  - Страницы услуг (например, `banki.tsx`, `girudoterapiya.tsx`) используют общие компоненты для контента.

- `src/components/` — **Функциональные блоки.**
  - Основные секции сайта (Hero, Services, FAQ, Education).
  - `ui/` — Базовые UI-компоненты (Shadcn, RollingGallery и т.д.).

- `src/lib/` — **Утилиты и логика.**
  - `typography.ts` — Правила русской типографики (неразрывные пробелы).
  - `utils.ts` — Хелперы для Tailwind (cn) и форматирования.

- `src/assets/` — **Ресурсы сборки.**
  - Метаданные изображений для оптимизации (TanStack Start).

- `public/` — **Статические файлы.**
  - `/images/` — Основное хранилище фотографий и иконок.
  - `/images/v2/` — Содержит дубликаты некоторых ресурсов из корня `/images/` (требует осторожности при обновлении).

## Основные компоненты и связи
- **BookingModal:** Глобальный компонент записи, вызывается через `BookingProvider` (в `index.tsx` и `ServicePage.tsx`).
- **ServicePage & PriceTable:** Используются на всех страницах конкретных услуг для единообразия верстки и цен.
- **TypographyProvider:** Обертка в `__root.tsx`, применяющая правила типографики ко всему тексту после гидратации.

## Правила редактирования
1. **НЕ МЕНЯТЬ** `src/routeTree.gen.ts` — файл генерируется автоматически.
2. **Типографика:** Весь текстовый контент должен проходить через `TypographyProvider` для корректного отображения (кавычки-ёлочки, тире, неразрывные пробелы).
3. **Цвета и шрифты:** Используйте семантические классы (`ds-h1`, `body-text`) и переменные из `src/styles.css`. Основной цвет текста — `#566A93`.
4. **Адаптив:** 
   - Мобильные заголовки: 24px-28px.
   - Отступы между блоками: 120px на мобильных/планшетах.
   - Десктопный брейкпоинт (`xl`) начинается с **1380px**.
   - Планшетный контейнер зафиксирован на **900px** (768px-1379px).
