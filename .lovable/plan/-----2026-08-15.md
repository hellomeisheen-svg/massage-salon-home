# Новая структура и логика квиза

## 1. Рефакторинг конфигурации квиза (`src/config/quiz.ts`)
- **Типизация**: Добавить `showIf` в `QuizStepConfig` для динамического отображения вопросов.
- **Ветвление**: Полностью переписать `steps` согласно новым веткам (Расслабление, Спина/Шея, Отёчность, Лицо, Оздоровление, Не знаю).
- **Сценарии**: Обновить `calculateResult` для строгой фильтрации по веткам.
- **Услуги**: Обновить базу услуг (цены, длительность, теги).

## 2. Обновление интерфейса (`src/components/quiz/QuizModal.tsx`)
- **Динамический прогресс-бар**: Расчет «Вопрос X из Y» на основе отфильтрованных по `showIf` шагов.
- **Авто-переход**: Улучшить плавность переходов между вопросами.
- **Сброс состояния**: Корректная очистка ответов при смене ветки.

## 3. Обновление результатов (`src/components/quiz/QuizResults.tsx`)
- **Ограничение**: Максимум 3 услуги в результате.
- **Приоритеты**: Массажи всегда перед оздоровительными практиками.
- **Акценты**: Пометка «Рекомендуем» для первой услуги (особенно Векторный для «Не знаю»).
- **Кнопки**: Добавить кнопку «Обсудить с мастером» (ссылка на WhatsApp/Telegram).

## Технические детали
- Использование `answers.goal` как ключа для ветвления.
- Изоляция ветки «Лицо» от услуг для тела.
- Обновление функции `submitQuizLead` для поддержки новой структуры данных.
