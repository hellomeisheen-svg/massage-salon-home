# План восстановления прелоадера

Для восстановления брендированного прелоадера будут внесены следующие изменения:

- **Файл:** `src/components/Preloader.tsx`
- **Точный компонент/секция:** Весь файл
- **Что изменится:** Компонент будет обновлен для соответствия новым требованиям: таймаут 2500мс, поддержка `prefers-reduced-motion`, визуальный стиль с пульсирующей звездой и индикатором загрузки.
- **Что гарантированно не будет изменено:** Бизнес-логика сайта, SEO-параметры, тексты и CTA.

- **Файл:** `src/routes/__root.tsx`
- **Точный компонент/секция:** Импорты и `RootShell`
- **Что изменится:** Добавлен импорт `Preloader` и его вызов в начале `body` внутри `RootShell`. Это обеспечит его появление при первоначальной загрузке страницы.
- **Что гарантированно не будет изменено:** Логика роутинга, обработка ошибок, мета-теги и подключение аналитики.

**Проверка:**
1. Первоначальная загрузка: прелоадер появляется сразу.
2. Скрытие: исчезает плавно после события `load` (когда Hero-изображение и шрифты готовы).
3. Таймаут: если загрузка затянется, прелоадер исчезнет через 2.5 секунды.
4. Переходы между страницами: прелоадер не должен появляться повторно (TanStack Router сохраняет `RootShell`).
5. Адаптив: проверка на mobile/tablet/desktop.

**Найденный старый компонент (для справки):**
Компонент находился в `src/components/Preloader.tsx` и был удален из `__root.tsx` в коммите `a3e135bc`. Он использовал `window.addEventListener("load", ...)` и имел защитный таймаут 2000мс.
