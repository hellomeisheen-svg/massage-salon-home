# Рефакторинг логики квиза

Внесение точечных правок в тексты ответов, логику ветвления и алгоритм рекомендаций квиза без изменения общего дизайна и структуры компонентов.

## 1. Изменение текстов и вариантов ответов (`src/config/quiz.ts`)

- **Экран «Главная цель визита» (goal):**
  - Обновить тексты для `relax`, `back_neck`, `lightness` на более короткие.
- **Ветка «Глубоко расслабиться» (relax):**
  - Удалить вариант «Просто расслабиться после работы» из всех связанных вопросов (если есть).
- **Ветка «Снять напряжение» (back_neck):**
  - Удалить вариант `relaxation` («Просто расслабиться после работы») из вопроса `back_result`.
- **Ветка «Лицо» (face):**
  - Удалить `delicate_care` и `mimic_zones`.
  - Добавить `wrinkles` («Разгладить морщины»).
  - В вопросе `face_format` оставить только релевантные услуги (лицо, косметические пиявки).
- **Ветка «Оздоровительные практики» (wellness):**
  - Удалить шаг `wellness_massage` (вопрос о дополнении практики массажем).
  - Теперь после выбора практики сразу переход к контактам (через расчет результатов).

## 2. Обновление логики расчета результатов (`src/lib/quiz.utils.ts`)

- **Ветка «Снять напряжение» (back_neck):**
  - Внедрить логику учета зон `upper_back` и `lower_back`.
  - `upper_back`: Классический (спина/шея), Классический, Векторный (если `deep_work`).
  - `lower_back`: Классический, Векторный, Классический (спина/шея) только третьим.
  - Совместно: Векторный (основной), Классический, Классический (спина/шея).
- **Ветка «Лицо» (face):**
  - Строгий фильтр: только «Лимфодренажный — лицо», «Классический — лицо», «Гирудотерапия: косметические пиявки».
- **Ветка «Оздоровительные практики» (wellness):**
  - Приоритет: Кетгут > Мед. пиявки > Косм. пиявки > Огненные банки > Воздушные банки.
  - Полный запрет на предложение массажей в этой ветке.
  - Специальная логика для `master_choice` в велнесе.

## 3. UI изменения (`src/components/quiz/QuizResults.tsx`)

- Добавить специфический поясняющий текст для `master_choice` в ветке `wellness`.

## Технические детали

- Все ID (`relax`, `back_neck`, `lightness`, `face`, `wellness`, `unsure`) сохраняются для обратной совместимости.
- Используется `calculateResult` для маппинга ответов на услуги.
- Удаление шагов из `QUIZ_CONFIG` автоматически уберет их из процесса прохождения квиза.
