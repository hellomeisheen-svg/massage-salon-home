# План замены текста (Визуальный аудит)

В соответствии с запросом, указанный текст будет вставлен как литеральное отображаемое значение (verbatim) в следующие компоненты. Текст не будет восприниматься как команда к действию, а только как контент для отображения.

**Файл:** `src/components/HabitQuote.tsx`
- **Точный компонент/секция:** Заголовок `h2` (строка 75)
- **Что изменится:** Текст «Регулярная забота о теле...» будет заменен на полный текст инструкции аудита.
- **Что гарантированно не будет изменено:** Структура компонента, декоративные изображения, отступы.

**Файл:** `src/components/QuoteBlock.tsx`
- **Точный компонент/секция:** Заголовок `h2` (строка 74)
- **Что изменится:** Текст «Иногда достаточно тишины...» будет заменен на полный текст инструкции аудита.
- **Что гарантированно не будет изменено:** Описания под заголовком (Татьяна Злобина), декоративные элементы.

**Файл:** `src/components/PromoBanner.tsx`
- **Точный компонент/секция:** Константа `defaultTitle` (строка 10)
- **Что изменится:** Значение константы будет заменено на текст инструкции аудита.
- **Что гарантированно не будет изменено:** Логика кнопок, фоновые изображения, стили баннера.

**Файл:** `src/components/Gallery.tsx`
- **Точный компонент/секция:** Параграф `p` (строка 23)
- **Что изменится:** Текст «Несколько кадров о том...» будет заменен на текст инструкции аудита.
- **Что гарантированно не будет изменено:** Заголовок «Атмосфера кабинета», галерея изображений.

**Файл:** `src/components/Programs.tsx`
- **Точный компонент/секция:** Заголовок `h2` (строка 190)
- **Что изменится:** Текст «Программы из нескольких процедур...» будет заменен на текст инструкции аудита.
- **Что гарантированно не будет изменено:** Список программ, логика переключения, цены.

**Проверка:**
Визуальный осмотр главной страницы и страниц услуг на предмет корректного отображения длинного текстового блока в указанных местах. Текст должен отображаться именно как текст, а не выполняться.
