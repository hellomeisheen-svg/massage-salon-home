# Варианты дизайна для ключевых блоков

Предлагаю два направления для обновления визуального языка сайта.

## Вариант А: «Тихая роскошь» (Quiet Luxury)
Фокус на пространстве, типографике и мягких переходах.
- **Секция «Мастер»:** Использование асимметричной сетки. Фото мастера занимает 60% ширины, текст накладывается с небольшим перекрытием на «стеклянной» подложке. Список школ выносится в горизонтальный скролл-бар с логотипами в приглушенных тонах.
- **Преимущества:** Уход от крупных цифр. Использование тонких линейных иконок и акцент на заголовках. Фон секции — очень мягкий градиент, имитирующий утренний туман.

## Вариант Б: «Интерактивный Бенто» (Modern Bento)
Фокус на структурированности и тактильности (как в iOS).
- **Секция «Мастер»:** Группировка информации в аккуратные карточки разного размера. Отдельная карточка для фото, отдельная для цитаты, сетка для дипломов. Каждая карточка имеет эффект «приподнятости» при наведении.
- **Преимущества:** Крупные цифры с градиентной заливкой (#1C3C8C -> #A2CFFE). Добавление фоновых геометрических фигур, которые медленно вращаются при скролле, создавая ощущение динамики.

## Общие улучшения для обоих вариантов
- **Микро-взаимодействия:** Плавное появление элементов (Reveal effect) при входе в область видимости.
- **Градиентные границы:** Использование исчезающих обводок для карточек, чтобы они казались частью фона, но имели четкую форму.
- **Улучшенный Blur:** Использование `backdrop-filter: blur(20px)` для всех плавающих элементов (Header, Modals).

### Технические изменения:
1. Создание новых утилит в `styles.css` для эффектов стекла и градиентных текстов.

3. Добавление `framer-motion` для плавных анимаций (по необходимости).
