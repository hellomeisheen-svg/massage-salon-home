# Редизайн блоков «Преимущества» и «Мастер»

Предлагаются варианты визуального обновления ключевых разделов сайта для повышения «премиальности» и визуальной глубины без изменения общей структуры контента.

## 1. Секция «Мастер» (IntroSection / Education)
Текущий вид: Текстовый блок и список дипломов рядом с фото.
Новый вариант: **Bento-структура с эффектом глубины.**

- **Композиция:** Слева крупное фото мастера в «парящей» карточке с мягкой тенью. Справа — сетка (bento grid) из карточек разного размера.
- **Интерактив:** Карточки образования получают легкий 3D-эффект (наклон) при наведении.
- **Акцент:** Добавление блока с цитатой прямо поверх фото (в углу) в виде «стеклянного» облачка (glassmorphism).

## 2. Секция «Преимущества» (StatsSection)
Текущий вид: Простая сетка с крупными цифрами.
Новый вариант: **Минималистичные карточки с микро-анимациями.**

- **Визуал:** Цифры заменяются на изящные начертания Noto Serif Display с градиентом от глубокого синего к нежно-голубому.
- **Структура:** Каждое преимущество оборачивается в карточку с очень тонкой обводкой и внутренним свечением.
- **Динамика:** При скролле цифры плавно «отсчитывают» значения от нуля до целевого.

## 3. Глобальные стили
- **Стеклянные поверхности:** Внедрение `backdrop-blur` для модальных окон и плавающих элементов.
- **Мягкие тени:** Замена текущих теней на многослойные (Layered Shadows) для создания эффекта естественного освещения.

## Технические подробности
- Использование CSS переменных для управления интенсивностью эффектов.
- Сохранение полной адаптивности и доступности (A11y).
- Оптимизация производительности: анимации через `transform` и `opacity`.
